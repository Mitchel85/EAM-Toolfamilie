Sichten-Archiv v1.0

Sichten und Layout aus einer .qea auslagern — Modell bleibt vollständig, Datei wird kleiner.

1 · Datei laden

Die Datei bleibt auf diesem Rechner. Es wird nichts hochgeladen, nichts gesendet.

.qea hierher ziehen oder klicken SQLite-Datei aus Sparx EA
–Dateigröße
–Sichten
–Platzierungen
–gezeichnete Kanten

2 · Umfang wählen

Beides wird vollständig gesichert und lässt sich zurückspielen.

Erzeugt zwei Dateien: *.archiv (Sicherung) und *_ohne_sichten.qea.
Die kompakte Datei ist zum Weitergeben oder Archivieren gedacht. Für die Bearbeitung in EA jederzeit die Sichten vorher zurückspielen.

3 · Sichten zurückspielen

Kompakte Datei plus zugehöriges Archiv wählen. Die Sichten kommen mit identischen Kennungen zurück.

Noch keine Dateien gewählt.
Bereit.
Läuft vollständig im Browser (sql.js). Keine Verbindung zu Sparx Systems, kein Bestandteil von Enterprise Architect. Direkte Schreibzugriffe auf .qea sind von Sparx nicht freigegeben — deshalb wird immer auf einer Kopie gearbeitet.
