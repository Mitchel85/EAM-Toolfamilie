ℹ️ Kurzanleitung — So erkunden, analysieren und exportieren Sie jede Architektur
  1. Direkt suchen (oben): Begriff eingeben (z. B. Prozess, System, Projekt) → sofort Treffer in 🖼️ Sichten, 📁 Paketen und 📦 Elementen.
  2. Durch Pakete & Sichten klicken: Im Reiter „🧭 Erkunden“ links durch den echten Ordnerbaum navigieren — rechts erscheinen Unterordner, alle vorhandenen Sichten (Diagramme) und Elemente, auch ohne ADMBw-Namensschema.
  3. Analysieren: Jede Sicht im Reiter „🕸️ Graph“ als Netzwerk erkunden (Knotenzahl per Schieberegler oder Zahleneingabe). Im Reiter „🔗 Verbindungen“ nachweisen, wie zwei Elemente zusammenhängen (Pfadanalyse mit Diagnose).
  4. Exportieren: Jede Sicht, jedes Paket und jeden Pfad mit einem Klick als 📸 PNG oder 📊 Excel (.xlsx) sichern — die Buttons stehen direkt an der jeweiligen Ansicht.
  5. Fragen stellen (Rückweg): Im Reiter „💬 Rückweg — Frage an das Modell“ einen Ausschnitt wählen (ganzes Modell, Paket oder Element), Frage eingeben und eine Textantwort erhalten — nur der Ausschnitt geht an die KI; die Antwort lässt sich als .md speichern.
  6. Bearbeiten: Im Reiter „✏️ Bearbeiten“ Elemente und Pakete auswählen und ändern — die Änderungen werden vorgemerkt und als neue .qea gespeichert.

5 · Ergebnis

💬 Verfeinern im Dialog

Die KI arbeitet als Gehilfe: Sie liefert präzise Operationen (hinzufügen, verbinden, entfernen …), die App führt sie lokal auf dem Modell aus. Nie geht das ganze Modell in den KI-Kontext — so skaliert das auch bei sehr großen Architekturen.

💬 Rückweg — Frage an das Modell — Ausschnitt wählen, fragen, Textantwort erhalten

Hier wird die geladene .qea gelesen, nicht verändert: Sie wählen einen Ausschnitt — ganzes Modell, ein Paket (mit Unterpaketen) oder ein einzelnes Element — und stellen dazu eine Frage. In den KI-Kontext geht nur dieser Ausschnitt als kompakter Text (Elemente, Pakete, Kanten, Tags), niemals die ganze Datei. Ohne hinterlegten API-Schlüssel erhalten Sie eine lokale Beschreibung des Ausschnitts — klar gekennzeichnet als „ohne KI“.
